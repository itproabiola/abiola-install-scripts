# Abiola DevOps – Installation & Automation Toolkit

A practical DevOps engineering portfolio and reusable toolkit containing installation scripts, automation utilities, infrastructure configuration and deployment resources.

**Maintainer:** Abiola DevOps
**GitHub:** [@itproabiola](https://github.com/itproabiola)

## About

This repository demonstrates practical work across cloud infrastructure, CI/CD, containerisation, configuration management, Kubernetes and Linux administration.

## Technology Stack

- AWS and Microsoft Azure
- Docker and Docker Compose
- Kubernetes, EKS, Kops and Helm
- Jenkins and CI/CD
- Terraform and Infrastructure as Code
- Ansible and configuration management
- Maven and Nexus
- SonarQube
- Nginx and Apache Tomcat
- Linux and Bash scripting

## Getting Started

Clone the repository:

```bash
git clone https://github.com/itproabiola/abiola-install-scripts.git
cd abiola-install-scripts

```

Review each script before execution. Check operating-system compatibility, permissions, configuration values and potential cloud costs.

## Security

- Never commit passwords, API tokens, private keys or `.env` files.
- Use `.env.example` for local configuration.
- Review cloud provisioning and deletion scripts before execution.
- Test learning examples before using them in production.
